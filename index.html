ПӘНДІ ОҚЫТУ МАҚСАТЫ

Пәннің мақсаты web-технологиялар негіздері, Интернет желісіне қатынас жасау технологиялары, Интернеттегі web-серверлер, статистикалық және динамикалық web-сайттар, қолданбалы бағдарламалар және программалау арқылы Web-бағдарламалауды жобалау негіздерін үйрету болып табылады.

ҚАЛЫПТАСАТЫН ОҚУ НӘТИЖЕЛЕРІ (ON)

ON 7: IP протоколдарының 4 және 6 нұсқаларының ерекшеліктерін, IP туннелдерін білу, сайттарды жобалау дағдыларын қалыптастыру.
ON 8: Браузерлердің гипермәтіндік ақпараттық жүйелерді құру принциптері; клиенттік веб-технологиялар (HTML, CSS, JavaScript, HTML5, Ajax, jQuery, XML); PHP, Frameworks (Yii, Laravel) және SQL/MySQL ДҚБЖ меңгеру.
ON 10: Академиялық адалдық пен жасанды интеллект (ЖИ) құралдарын этикалық пайдалану талаптарын сақтау, ақпараттың дұрыстығын бағалау.
Пререквизиттер: Ақпараттық жүйелер негіздері, Алгоритмдеу, Деректер қоры, ОӨБ.
Постреквизиттер: Мамандандыру пәндері, Курстық жоба, Дипломдық жұмыс.

Білім алушылар Академиялық адалдық кодексін қатаң сақтауы тиіс. Жасанды интеллект (AI) құралдары университет саясатына сәйкес этикалық түрде тек көмекші құрал ретінде пайдаланылады.

7. Бағалау саясаты

Студенттердің оқу жетістіктері 100 балдық шкала бойынша бағаланады (1P, 2P rating бақылаулары).

Рейтинг есептеу формулалары:

1АБ (2АБ) = (Дәріс + Зерт + БӨЖ + БОӨЖ) / n
1Р (2Р) = (Ағымдық бақылау + Аралық бақылау) / 2
Құраушы Рейтинг (ҚР) = (1Р + 2Р) / 2
Емтиханға жіберу шарты: Рұқсат беру рейтингі (ҚР) кемінде 50% болуы тиіс.

1-қадам: GitHub-та жаңа репозиторий құру

1. GitHub.com сайтына кіріп, New Repository батырмасын басыңыз.

2. Репозиторий атауын жазыңыз (мысалы: web-syllabus-book).

3. Public режимін таңдап, Create repository басыңыз.

2-қадам: Осы HTML файлын жүктеу

1. Репозиторий ішінде Uploading an existing file сілтемесін басыңыз.

2. Осы кодты сақтаған index.html файлын сүйреп әкеліп жүктеңіз.

3. Төмендегі Commit changes батырмасын басыңыз.

3-қадам: GitHub Pages-ті іске қосу

1. Репозиторийдің Settings (Баптаулар) бөліміне өтіңіз.

2. Сол жақ мәзірден Pages секциясын таңдаңыз.

3. Branch бөлімінен main (немесе master) таңдап, Save басыңыз.

4. 1-2 минутта сіздің кітабыңыздың сілтемесі дайын болады! (мысалы: https://username.github.io/web-syllabus-book/)
